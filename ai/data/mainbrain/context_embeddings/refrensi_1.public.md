## Ringkasan Penelitian & Metodologi (Referensi 1)

**Judul**: Penerapan Natural Language Processing untuk Analisis Sentimen Terhadap Kebijakan Pemerintah.
**Objek Kebijakan**: Undang-Undang Cipta Kerja (Omnibus Law).
**Dataset**: **75.000 komentar dan postingan publik** dari berbagai platform media sosial dan berita daring.
**Metode NLP & Model**:
- **Recurrent Neural Network - Long Short-Term Memory (RNN-LSTM)** untuk klasifikasi sentimen sekuensial secara keseluruhan.
- **Aspect-Based Sentiment Analysis (ABSA)** untuk membedah sentimen berdasarkan aspek spesifik kebijakan (hak buruh, dampak lingkungan, dan kemudahan investasi).
