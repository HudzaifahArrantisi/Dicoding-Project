# Cara Minta Review dari Rekan Tim

## 🎯 Kapan dipakai
Pakai ini setelah kamu membuat Pull Request di GitHub dan ingin meminta teman satu kelompok atau *tech lead* untuk meninjau kodemu agar mendapatkan *approval*.

## 📝 Istilah penting
- Reviewer: orang yang ditugaskan untuk membaca dan menyetujui Pull Request.
- Assignee: penanggung jawab utama pengerjaan fitur tersebut (kamu sendiri).

## ✅ Langkah-langkah
1. Buka halaman Pull Request milikmu di GitHub.
2. Di bilah samping sebelah kanan (*sidebar*), cari bagian **Reviewers**.
3. Klik ikon roda gigi atau klik kolom pencarian di bagian **Reviewers**.
4. Pilih username GitHub teman satu kelompokmu yang ingin diminta review.
5. GitHub akan secara otomatis mengirimkan notifikasi email dan tanda pemberitahuan di dashboard GitHub mereka.
6. *(Tips tim cepat):* Salin link URL halaman Pull Request tersebut (contoh: `https://github.com/organisasi/repo/pull/12`) dan bagikan ke grup WhatsApp atau Discord timmu.
