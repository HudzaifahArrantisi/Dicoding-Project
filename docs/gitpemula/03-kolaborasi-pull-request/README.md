# Kolaborasi dan Pull Request: 10 panduan

Panduan kategori ini akan ditulis pada batch berikutnya.

21. Bikin Pull Request.
22. Review dan merge Pull Request dengan `git merge`.
23. Perbarui repo lokal setelah PR digabung.
24. Fork repo dan sinkron dengan repo asli.
25. Kerja bersama pada satu file.
26. Minta review dari rekan tim.
27. Perbaiki kode setelah komentar review.
28. Batalkan Pull Request yang belum digabung.
29. Tulis deskripsi Pull Request yang mudah diperiksa.
30. Pastikan branch siap sebelum meminta merge.
