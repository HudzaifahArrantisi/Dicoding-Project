# Cara Lihat Perubahan Baris dengan Git Diff

## 🎯 Kapan dipakai
Pakai ini sebelum melakukan `git add` untuk melihat baris kode mana saja yang baru saja kamu tambahkan (berwarna hijau `+`) atau kamu hapus (berwarna merah `-`).

## ✅ Langkah-langkah
- **Lihat semua perubahan baris yang belum di-add**:
  ```bash
  git diff
  ```
- **Lihat perubahan pada satu file tertentu saja**:
  ```bash
  git diff <nama-file>
  ```
