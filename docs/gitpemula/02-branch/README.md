# Branch: 10 panduan

Panduan kategori ini akan ditulis pada batch berikutnya.

11. Cek branch lokal dan GitHub.
12. Bikin branch baru untuk fitur.
13. Pindah branch dengan aman.
14. Ambil perubahan terbaru `main` ke branch kerja.
15. Hapus branch lokal yang sudah selesai.
16. Hapus branch di GitHub.
17. Ganti nama branch.
18. Ambil branch teman dari GitHub.
19. Bersihkan daftar branch GitHub yang sudah dihapus.
20. Kembali ke branch sebelumnya.
