# Cheat Sheet Perintah Git Harian

Tabel ringkas perintah Git yang paling sering digunakan dalam pengembangan perangkat lunak sehari-hari:

| Tujuan | Perintah Git |
|---|---|
| **Cek status file** | `git status` |
| **Cek branch aktif** | `git branch --show-current` |
| **Tarik update terbaru** | `git pull origin main` |
| **Bikin branch baru** | `git checkout -b <nama-branch>` |
| **Pindah branch** | `git checkout <nama-branch>` |
| **Simpan semua editan** | `git add .` |
| **Buat commit** | `git commit -m "feat: pesan commit"` |
| **Push pertama kali** | `git push -u origin <nama-branch>` |
| **Push berikutnya** | `git push` |
| **Simpan darurat** | `git stash` / `git stash pop` |
| **Lihat riwayat singkat** | `git log --oneline -10` |
| **Batalkan editan file** | `git restore <nama-file>` |
| **Batalkan merge macet** | `git merge --abort` |
| **Bersihkan branch lama** | `git fetch --prune` |
