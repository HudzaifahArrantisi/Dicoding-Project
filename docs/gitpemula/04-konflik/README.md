# Konflik: 10 panduan

Panduan kategori ini akan ditulis pada batch berikutnya.

31. Baca dan selesaikan konflik saat merge.
32. Selesaikan konflik saat pull.
33. Batalkan merge yang masih konflik.
34. Cegah konflik sebelum mulai mengubah kode.
35. Kenali penanda konflik dalam file.
36. Selesaikan konflik ketika file dihapus dan diubah.
37. Selesaikan konflik saat cherry-pick.
38. Pastikan tidak ada penanda konflik tertinggal.
39. Minta bantuan tim saat pilihan perubahan tidak jelas.
40. Lanjutkan pekerjaan setelah konflik selesai.
