# Cara Hapus File dari Repo dan Folder Sekaligus

## 🎯 Kapan dipakai
Pakai ini saat kamu ingin membuang sebuah file kode yang sudah tidak dipakai, baik dari catatan riwayat Git maupun dari harddisk komputermu secara bersamaan.

## ✅ Langkah-langkah
1. Jalankan perintah `git rm`:
   ```bash
   git rm <nama-file>
   ```
2. Commit tindakan penghapusan tersebut:
   ```bash
   git commit -m "chore: hapus file lama yang sudah tidak digunakan"
   ```
