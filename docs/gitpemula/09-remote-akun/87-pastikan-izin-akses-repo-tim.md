# Cara Pastikan Izin Akses ke Repo Tim (Collaborator)

## 🎯 Kapan dipakai
Pakai ini saat rekan satu timmu mendapatkan error `Permission to ... denied to user` atau `Repository not found` saat mencoba melakukan clone atau push ke repository bersama.

## ✅ Langkah-langkah
1. Pemilik repository (*owner*) harus membuka GitHub:
   - Buka repo -> **Settings** -> **Collaborators**.
   - Klik **Add people**, masukkan username GitHub rekan tim.
2. **PENTING**: Rekan tim yang diundang **WAJIB membuka email atau tautan undangan** dan mengklik tombol **Accept invitation**.
3. Sebelum undangan diterima (*accepted*), rekan tersebut belum memiliki izin untuk melakukan push ke repository!
