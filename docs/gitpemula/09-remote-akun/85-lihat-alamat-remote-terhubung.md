# Cara Lihat Alamat Remote yang Terhubung

## 🎯 Kapan dipakai
Pakai ini saat kamu ingin memastikan proyek lokalmu saat ini terhubung ke repositori GitHub yang mana, atau ingin mengecek apakah alamat remote sudah benar.

## ✅ Langkah-langkah
Jalankan perintah remote dengan opsi `-v` (*verbose*):
```bash
git remote -v
```

Contoh output yang benar:
```text
origin  https://github.com/HudzaifahArrantisi/Dicoding-Project.git (fetch)
origin  https://github.com/HudzaifahArrantisi/Dicoding-Project.git (push)
```
