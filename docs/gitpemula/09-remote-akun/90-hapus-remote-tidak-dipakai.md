# Cara Hapus Remote yang Tidak Dipakai

## 🎯 Kapan dipakai
Pakai ini saat kamu memiliki remote cadangan atau remote lama (misal `upstream` atau `temp`) yang sudah tidak digunakan lagi dan ingin dibersihkan.

## ✅ Langkah-langkah
Jalankan perintah remove:
```bash
git remote remove <nama-remote>
```
*Contoh:*
```bash
git remote remove upstream
```

Cek daftar yang tersisa:
```bash
git remote -v
```
